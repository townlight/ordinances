CivicCode

Municipal code and ordinance access, designed to answer code questions with exact citations while keeping legal interpretation with city staff.

Durable code, discovery, staff-note, plain-language summary, CivicClerk handoff, local import-job, codifier sync-state, and operational retry/replay/cursor runtime online on the Docker/PostgreSQL path, alongside configured Ollama embedding retrieval with PostgreSQL pgvector ranking, local Ollama source-bounded answer support, a React/Vite resident app, related-section navigation aids, mock-city codifier contracts, staff code lifecycle workspace, staff workbench foundation, staff source registry, records-ready export and accessibility hardening, local import, public lookup, CivicClerk handoff warnings, citation-grounded Q&A, citation contract, search and permalink, database-backed source registry, runtime foundation, and canonical schema foundations - legal determinations, bundled vendor credentials, CivicAccess runtime dependency, and automatic ordinance codification not available

What CivicCode does

  • Import authoritative municipal code sources from local fixtures and file drops.
  • Verify source-attributed real municipal code fixtures through the same local import, search, and cited-answer path.
  • Preserve section versions and effective dates.
  • Export records-ready section packages with citations and source provenance.
  • Answer routine code questions with citations.
  • Resolve adopted section context for downstream CivicSuite modules.
  • Label summaries as non-authoritative.

What it will not do

  • Replace the official codifier.
  • Give legal advice.
  • Automatically codify ordinances.
  • Start CivicZone runtime work.
